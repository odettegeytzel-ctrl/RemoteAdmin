Conecta un nuevo equipo

Descarga el instalador de RemoteAdmin para Windows y ejecútalo en el equipo que deseas administrar.

  1. Descarga el instalador y cópialo al equipo.
  2. Descomprímelo y ejecuta installer\install-agent.ps1 en PowerShell como administrador.
  3. Pega la credencial de instalación cuando te la pida.
  4. Espera a que el equipo aparezca en Dispositivos.

Instalador para Windows

Se abre y se sigue. No hace falta Python ni abrir ninguna consola.

Paquete comprimido, para instalar a mano o automatizar. Requiere Python en el equipo y una consola.

Credencial de instalación

Autoriza el alta de un equipo en tu organización. Se muestra una sola vez: el servidor guarda únicamente su huella y no puede volver a enseñarla. En cuanto el equipo aparezca, puedes revocarla.
